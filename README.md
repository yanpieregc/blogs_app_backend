# App de Blogs(Back-end)
Aplicación que permite administrar blogs.

## Front-end
https://github.com/yanpieregc/blogs_app_frontend

## Tecnologías
- JavaScript
- Node.js
- Express
- MongoDB
- JWT

## Funcionalidades
- Registro de usuarios
- Inicio de sesión
- Crear blogs
- Votar blogs
- Eliminar blogs

## Instalación
- pnpm install
- pnpm start
